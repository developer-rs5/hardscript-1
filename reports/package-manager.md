# Package Manager Report

_Generated by `hard report`. Do not edit — regenerated on demand._

## Overview

M4.0 introduces the HardScript package manager: a dependency registry
client (no server ships yet), deterministic resolver, shared cache and
`hard add / remove / install / update / list / outdated / search / info`.

## Commands

| command | role |
|---------|-----|
| `hard init` | scaffold a manifest in the current directory |
| `hard new <name>` | scaffold a project or template |
| `hard add <pkg>` | add + resolve + install a dependency |
| `hard remove <pkg>` | remove a dependency |
| `hard install` | install everything in the lockfile |
| `hard update [pkg]` | bump to newest matching versions |
| `hard list` | show installed packages |
| `hard outdated` | show packages with newer releases |
| `hard search <q>` | search the registry |
| `hard info <pkg>` | show package metadata |

## Storage

- Manifest: `hard.toml` (schema `1`, `edition "2027"`).
- Lockfile: `hard.lock` (schema `hard-lock/v1`).
- Cache: `$HARD_HOME/cache` or `~/.hard/cache`.
- Archive format: `.hspkg` (magic `HSPKG\0\x01`), integrity = SHA-256.
