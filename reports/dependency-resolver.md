# Dependency Resolver Report

_Generated by `hard report`. Do not edit — regenerated on demand._

## Semver

Supported requirement operators: exact `1.2.3`, caret `^1.2`,
tilde `~1.2.3`, wildcard `1.2.*`, comparator sets `>=1.0,<2`. Prerelease
versions (`-beta.1`) only match when the requirement itself is a
prerelease of the same base.

## Resolution

The resolver builds a global index of every known version, then walks
the graph from the root package in deterministic topological order.
Conflicts are re-negotiated by reassigning dependency requirements;
cycles are reported as errors rather than silently broken.

## Errors

| code | meaning |
|------|---------|
| `not-found` | package does not exist |
| `unresolvable` | no version satisfies the requirement |
| `conflict` | requirements disagree on a package |
| `duplicate` | same package declared twice |
| `circular` | dependency cycle detected |
| `invalid-req` | malformed version requirement |
