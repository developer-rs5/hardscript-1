## Stress-lab highlights (measured)

- Router growth: keep-alive mixed @ c512 = 30–38k RPS from 3 → 10000 routes (0 err).
- Concurrency sweep: keep-alive stays ≥ 30k up to c1024; no collapse.
- Payload sweep: 1 KB → 34.5k, 10 KB → 14.7k, 100 KB → 2.0k, 1 MB → 168 RPS, 0 err every size.
- WebSocket: 5000 concurrent clients connect+join in <1 s; 5000 × 1 broadcast round-trip = 3.4k msg/s, p50 0.68 ms, 0 err.
- All 0 client errors across the lab.

## New runtime capabilities (v0.2-alpha)

- Zero-copy HTTP request parsing (ms1.1)
- Request arena allocator; ~1 allocation per request (ms1.2)
- HTTP keep-alive with TCP_NODELAY (ms1.5)
- Connection worker pool, grow-on-demand, lazy + shrinkable (ms1.3, ms1.9)
- Streaming, allocation-free JSON encoder (ms1.4)
- Trie + static-direct-map router with wildcard/param (ms1.6)
- Value-engine foundation: tagged-union Value, ConstPool, Val bridge (ms2.0)
- Tagged-union value engine: spec kind set, inline primitives, Function kind, pinned layout/SSO, layout report (ms2.1)
- Small string optimization: SSO 14 → 24, 32 B tagged union, UTF-8-safe boundaries, zero-alloc strings ≤ 24 B (ms2.2)

## New compiler capabilities (v0.2-alpha)
